# Tournament progression view — draft

This view presents stages as an ordered sequence, rather than a graphical bracket, to accommodate flexible formats. Viewers can select a stage to inspect its results without administrator access. The selected view stays in place; the optional follow-updates mode highlights new results without switching views.

Participants are filled into the next stage when advancement from the preceding stage has been resolved, including any required tie-breaker. There are no placeholder names or live projected qualifiers for now. Conditional tie-breakers remain hidden until needed.

For the first event, the view can show the initial combined standings, multiplayer elimination order as it is entered, and the fighting final. Qualifying positions should be marked more prominently. The fighting final shows both players and the current round-win count, and the result-entry tab also displays that count as rounds are recorded. The tournament winner is clearly identified once determined.

The precise visual design and how qualifying positions are marked remain open. Entries and corrections follow the existing access rules.

An elimination stage can be closed from its own tab without administrator access once the elimination order is complete; the next stage receives its eligible players. Reopening a closed stage remains an administrator action.
